ZACHARY'S SNACKERY — ONE-TIME FIREBASE SETUP

The website code now:
1. Validates/builds the order in the browser.
2. Saves successful orders to Firestore collection: orders
3. Creates two email jobs in Firestore collection: mail
   - owner notification -> zacharyssnackery@gmail.com
   - customer confirmation -> customer's email
4. Redirects to thank-you page only after Firestore accepts the batch write.

EMAIL DELIVERY (required one-time setup)
The website intentionally does NOT contain Gmail/SMTP credentials.
Install Firebase's official "Trigger Email" extension on the existing Firebase project and configure it to watch the collection named: mail
Configure the extension with an SMTP provider/account you control.
Once installed, the mail documents created by order.js are sent automatically.

FIRESTORE RULES
Your Firestore security rules must allow the public site to create documents in `orders` and `mail`, while preventing public reads of those collections. Do not make customer orders publicly readable.

IMPORTANT LOCAL DELIVERY NOTE
The public site does not contain or expose the owner's exact home address. The customer sees only Orlando / Dr. Phillips 32836 and confirms they are within the 25-mile service area. Exact automated mileage requires a private server-side geocoding/distance service; it should not be implemented by placing the home address in browser JavaScript.

CURRENT PRICING IMPLEMENTED

Shipping: $25 per 20-cookie shipping box.
If shipping pricing above 20 cookies should use a different rule, change price() in order.js before publishing.
